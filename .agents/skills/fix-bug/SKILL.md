# Fix Bug

## Workflow

1. Understand expected and actual behavior.
2. Reproduce the issue or identify the failing test/log evidence.
3. Locate relevant files with search or context tools.
4. Read exact source files and nearby tests.
5. Trace the likely root cause.
6. Make the minimal fix that follows existing patterns.
7. Add or update a regression test.
8. Run relevant verification.
9. Document root cause and behavior changed.

## Output

- Root cause.
- Fix summary.
- Regression coverage.
- Verification run.
- Remaining risk, if any.
