# Context Maps

Context maps are compact navigation files. They should point agents to exact source areas without replacing source truth.

Create or update maps when routes, schemas, ownership rules, deployment shape, test layout, or major workflows change.

## Lumina Maps

- `agent-map.md`: role and skill routing.
- `api-map.md`: backend API endpoints, frontend clients, and contract tests.
- `backend-map.md`: NestJS domains, integrations, common helpers, and backend guardrails.
- `frontend-map.md`: Next.js routes, domain components, client services, and browser-editing guardrails.
- `database-map.md`: MongoDB schemas, repositories, ownership rules, and token/history storage rules.
- `deployment-map.md`: runtime shape, env vars, hosting files, and deployment guardrails.
- `testing-map.md`: verification commands, test locations, and test-selection hints.

`application-map.md`, `service-map.md`, and `data-map.md` are compatibility aliases for generic template routing.
