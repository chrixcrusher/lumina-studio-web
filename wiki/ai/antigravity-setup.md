# Gemini And Antigravity Setup

Gemini/Antigravity-style agents should start with `GEMINI.md`, which points to `AGENTS.md`.

Use:

- `.agents/skills/` for repeatable workflows.
- `.agents/roles/` for task responsibilities.
- `.agents/tools/context-strategy.md` for token-efficient navigation.
- `.agents/tools/verification-commands.md` for actual repo commands.

Do not duplicate rules across tools. Keep `AGENTS.md` authoritative and update adapters only when tool-specific behavior changes.
