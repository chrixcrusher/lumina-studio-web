You are Codex acting as a senior AI engineering architect and repository automation engineer.

Your task is to convert this existing development project into an AI-driven development setup that works well with Codex first, but remains portable to Claude Code, Cursor, Google Antigravity, Gemini CLI, Cline, Windsurf, GitHub Copilot-style tools, and other agentic coding assistants.

Do not make random large application changes. This task is about adding an AI development control plane around the project: agent instructions, reusable skills, role/persona files, tool policies, context strategy, verification commands, and documentation.

## Main Goal

Create a maintainable, scalable, token-efficient AI-assisted development structure for this repository.

The final setup must support:

1. Custom agents/personas/roles
2. Reusable skills/workflows
3. Tool usage policies
4. Context and token-efficiency strategy
5. Graphify-based codebase navigation
6. Optional Aider repo-map guidance

## Important Philosophy

Use this model:

* Rules define behavior.
* Skills define repeatable workflows.
* Agents define responsibilities.
* Tools provide capabilities.
* Docs provide truth.
* Graphs help navigation.
* Source files remain the final truth.
* Tests verify correctness.

Graphify, Aider repo maps, and similar tools should reduce wasted context, but they must not replace reading exact source files before editing code.

The correct workflow is:

1. Use Graphify or repo-map tools to identify relevant files.
2. Read exact files before making changes.
3. Make small, reviewable edits.
4. Run tests, lint, typecheck, and build where available.
5. Update docs if behavior changes.
